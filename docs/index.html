Capabilities

Built for Power Users

Everything you loved about IDM, rebuilt with a stunning interface, modern security, and zero annual subscription.

⚡

32-Stream Multi-Segment Engine

Splits HTTP/HTTPS downloads into up to 32 parallel byte-range streams, saturating your connection and cutting large-file times by 8×.

🛡️

VirusTotal Cloud Antivirus

SHA-256 checksums are computed on completion and submitted to VirusTotal's 70+ engine API — malware blocked before it ever runs.

🎬

Native yt-dlp Media Pipeline

Extract 4K, 1080p, 720p video or MP3/M4A/FLAC audio from YouTube and 1000+ sites. Choose format and quality right from the UI.

🧩

Browser Extension & Video Sniffer

One-click "Download with MDM" intercept for Chrome, Edge, Brave and Firefox. Auto-fading floating button on media pages.

📊

Live Bandwidth Wave Graph

Real-time SVG speed graph animates per-second throughput so you can instantly see your connection performance at a glance.

🔒

100% Private · Zero Nags

No telemetry, no user tracking, no serial key prompts. Runs on local loopback (127.0.0.1:9666). MIT licensed forever.

Workflow

Stupidly Simple

Paste a URL, pick your settings, hit Download. That's it.

01

Install & Launch

Drop the portable .exe anywhere or run the installer. No admin rights needed for the portable build. Starts in under a second.

02

Paste a URL

Click "Add Download", paste any HTTP/HTTPS link or YouTube URL. MDM auto-detects media and suggests quality options.

03

Watch It Fly

Up to 32 parallel streams attack the file at once. Monitor per-second bandwidth on the live graph as it finishes in seconds.

04

Open Clean Files

VirusTotal auto-scans on completion. A green "CLEAN" badge confirms zero threats across 70+ engines before you open anything.
